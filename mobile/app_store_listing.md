## Before pressing "Add for Review"

- **App Privacy** — must declare face data collection. The signup flow captures a face photo and sends it to Luxand for recognition, so it has to be disclosed (Sensitive Info / Biometric, plus Photos depending on storage). A blank privacy card is a rejection.
- **App Review notes + demo account** — reviewers cannot test face search without an account that already has an event containing photos of a registered face. Supply credentials and a short walkthrough, otherwise it comes back as "unable to review".
- **Export compliance** — the app ships end-to-end encrypted chat (see `ENCRYPTION.md`), so answer the build's encryption question accordingly rather than accepting the default "no".
- **Requests are reviewed before they go live.** A posted request lands in admin review and only reaches the board once approved, so a reviewer who posts one will not see it appear. Say so in the review notes, or supply a demo account with a request already approved — otherwise the flow reads as broken.
